# 🧵 Mujawar Textile

An AI-powered textile management application designed to make textile factory operations smarter, faster, and more efficient.

## 🌐 Live Demo

🔗 **[Mujawar Textile](https://rehan1.ccbp.tech/)**

## 📌 About the Project

Mujawar Textile is a smart textile management platform that uses AI and automation to simplify common textile factory operations.

The application focuses on fabric quality inspection, employee attendance, and leave management, helping reduce manual work and improve operational efficiency.

## ✨ Key Features

- 🔍 **AI Fabric Detection**
  - Upload fabric images for analysis.
  - Detect possible fabric defects.
  - Display detection results and confidence information.

- 📷 **Face Recognition Attendance**
  - Automates employee attendance.
  - Uses face recognition for employee identification.

- 🏖️ **Leave Management**
  - Employees can submit leave requests.
  - Management can review and manage requests.

- 📊 **Management Dashboard**
  - Provides an overview of textile operations.
  - Helps monitor employees and inspection activities.

- 📱 **Responsive Design**
  - Easy-to-use interface.
  - Works across different screen sizes.

## 🎯 Project Objective

The main objective of Mujawar Textile is to introduce AI-powered automation into textile businesses and reduce the dependency on manual processes.

## 🧠 AI Integration

The project uses AI for fabric inspection and defect detection.

The system can help identify:

- Fabric type
- Fabric defects
- Detection confidence
- Quality inspection status
